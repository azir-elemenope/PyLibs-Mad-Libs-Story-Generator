# PyLibs
An interactive Python Mad Libs-style story generator

# About
**PyLibs** is a Python program that creates a personalized story based on the user's input. The program asks the user to provide information such as names, numbers, and other words then inserts these inputs into a predefined story template tackling about the displacement of the Aetas, an indigenous people in the Philippines, and explores themes of relocation, indigenous rights, injustice, and consequences. Combining programming concepts with a narrative inspired by social issues.

# Note
This is a laboratory activity for my Math 153 course, developed as a learning exercise to practice fundamental Python programming concepts through creative, interactive story generator. This project represents my first step in learning how to write code, solve problems, and turn an idea into a working program, reflecting an important part of my early programming journey.
